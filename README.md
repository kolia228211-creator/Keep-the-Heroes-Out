# Ходу героям нема! (Keep the Heroes Out)

Неофіційна фанатська версія настільної гри для особистої гри з друзями. Оригінальна гра — Льюїс Брюе, українське видання — «Ігромаг».

## Як встановити (для гравців)

1. Відкрийте [Releases](https://github.com/kolia228211-creator/keep-the-heroes-out/releases/latest) і завантажте `HoduHeroyamNema-Setup-….exe`.
2. Запустіть файл. Windows може показати синє вікно «Windows захистила ваш ПК» — програма не підписана платним сертифікатом. Натисніть **«Докладніше» → «Виконати однаково»**.
3. Далі звичайний інсталятор: обрати папку, ярлик на робочому столі. Видалити гру можна через «Параметри → Програми».

Оновлювати вручну нічого не треба: під час кожного запуску програма сама перевіряє, чи вийшла нова версія гри, і завантажує її. Без інтернету запускається остання завантажена версія.

## Гра з друзями по мережі

Як у Minecraft: один гравець відкриває гру, інші підключаються до нього.

1. Усі вмикають **Radmin VPN** і заходять в одну мережу (якщо граєте в одній квартирі — можна й без нього).
2. Хост: **Гра по мережі → Відкрити гру для мережі**, обирає сценарій і кланів, тисне «Відкрити гру для мережі». Програма покаже адресу на кшталт `26.12.34.56:47777` (адреси Radmin виділені зеленим) — її треба надіслати друзям.
3. Коли Windows спитає про брандмауер — поставте **обидві галочки** і натисніть «Дозволити доступ». Без цього друзі не підключаться.
4. Друзі: **Гра по мережі → Підключитися до гри друга**, вводять ім’я й адресу, обирають свій клан.

Значок 🌐 угорі показує, хто зараз у грі. Хост може зберегти мережеву партію й пізніше відкрити її знову: **Збереження → 🌐 Для мережі**. У всіх має бути однакова версія гри — програма оновлюється сама, тож достатньо перезапустити її.

Перевірити самому на одному комп’ютері: запустіть другу копію з `HHN_PROFILE=2` і підключіться до `127.0.0.1:47777`.

## Як це влаштовано

```
game/            код гри (спільний для сайту й програми)
  src/           data.js, scen.js, engine.js, art.js, ui.js, tut.js, style.css
  build.js       збирає гру в один HTML: game/dist/index.html (програма) або --web (сайт)
  VERSION        версія гри
desktop/         програма для Windows (Electron)
  src/main.js    вікно, лаунчер, запуск гри через hhn://game/
  src/game-updater.js   завантаження оновлень гри з updates/ у цьому репозиторії
  src/lan.js     гра по мережі: сервер у хоста (порт 47777) і клієнт з перепідключенням
  scripts/release-game.js  випуск нової версії гри
  test/          тести оновлювача
updates/         опубліковані пакети гри для лаунчера (game.json + game-X.Y.Z.zip)
.github/workflows/desktop-release.yml  збірка інсталятора на серверах GitHub
```

Є два рівні оновлень:

- **Гра** (правила, карти, графіка) — пакет у `updates/`. Лаунчер читає `updates/game.json`, качає zip, звіряє контрольну суму й розпаковує в `%APPDATA%\HoduHeroyamNema\game\<версія>`. Інсталятор перезбирати не треба.
- **Програма** (сама оболонка .exe, мережа) — рідко. Нова версія публікується в GitHub Releases, програма помічає її у фоні й пропонує перезапуститися.

Збереження гри лежать у `%APPDATA%\HoduHeroyamNema` і не зникають при оновленнях.

## Випустити оновлення гри

```bash
cd desktop
npm ci
npm run game:release -- 1.0.1     # нова версія гри
git add ../game ../updates && git commit -m "Гра 1.0.1" && git push
```

Друзі отримають її під час наступного запуску (GitHub може віддавати старий файл ще до 5 хвилин).

Якщо гра почала потребувати нових можливостей програми, вкажіть мінімальну версію програми: `npm run game:release -- 2.0.0 --min-shell 0.2.0`. Тоді старі програми продовжать запускати попередню версію гри, доки не оновляться самі.

## Випустити нову версію програми (.exe)

1. Підняти `version` у `desktop/package.json` (наприклад `0.2.0`) і запушити в `main`.
2. GitHub Actions побачить, що релізу `v0.2.0` ще немає, збере інсталятор на Windows і опублікує його в Releases (≈5–10 хв). Встановлені програми оновляться самі.

Зібрати без публікації: вкладка **Actions → «Збірка програми для Windows» → Run workflow**, готовий `.exe` буде в артефактах запуску.

## Розробка

```bash
cd desktop
npm ci
npm start     # зібрати гру й відкрити програму
npm test      # тести оновлювача
```

`HHN_MANIFEST_URL=http://127.0.0.1:8765/game.json npm start` — перевірити оновлення з локального сервера. Журнал лаунчера: `%APPDATA%\HoduHeroyamNema\launcher.log`.

Гарячі клавіші в програмі: **F11** — повний екран, **F5** / **Ctrl+R** — перезавантажити, **F12** — інструменти розробника.
